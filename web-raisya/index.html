Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia:

Shared Hosting

Layanan hosting di mana satu server fisik digunakan bersama-sama oleh banyak pengguna. Sumber daya (CPU, RAM) dibagi rata, sehingga harganya terjangkau namun performa bisa saling memengaruhi.

Dedicated Server

Jenis layanan penyewaan seluruh server fisik secara eksklusif untuk satu pengguna saja. Menawarkan performa maksimal, kontrol penuh, dan keamanan tingkat tinggi tanpa berbagi dengan pihak lain.

Amazon Lightsail

Layanan *Virtual Private Server (VPS)* pemula dari AWS yang dirancang dengan harga terjangkau dan prediktif. Sangat mudah digunakan untuk deployment aplikasi sederhana, web server, atau blog.

Amazon EC2 (Elastic Compute Cloud)

Layanan cloud computing berskala besar dari AWS yang menyediakan kapasitas komputasi fleksibel di cloud. Memungkinkan pengguna mengontrol penuh sistem operasi dan konfigurasi jaringan sesuai kebutuhan aplikasi kompleks.
